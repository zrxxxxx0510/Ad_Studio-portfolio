01 策略结构：为什么拆成钩子 / 展示 / 转化？

× 让用户直接模仿整条爆款视频

✓ 拆成钩子 / 展示 / 转化三类广告策略单元

行业洞察

  • TikTok For Business 在广告创意最佳实践中建议，表现型广告应遵循“钩子 - 突出核心卖点 - 明确行动号召”的结构：前几秒抓住注意力，中段突出产品价值，结尾引导用户点击、购买或进入店铺。

策略标注流程

因此，我们先获取 TikTok 上美妆类近 3 个月高表现的 10000+ 条视频，由 LLM 初步识别每条视频中的钩子、展示和转化片段，再对策略进行初步归纳。随后我们人工合并相近类别、整理命名，并为视频标注对应的策略类型，使系统能够基于策略单元进行推荐、组合和后续生成。

02 爆款学习：为什么基于 Top-20 归纳策略？

× 展示 3 条相似爆款视频供用户模仿

✓ 基于 Top-20 相似高表现视频归纳 3 组策略组合

爆款学习机制

  • 召回相似产品，而不是只找表面相似视频。 系统先进行商品诊断，识别商品的六类关键信息：品类、核心卖点、目标人群、使用场景、用户痛点和平台语境。随后，系统基于这些诊断结果进行 RAG 召回。召回结果中既包含品类相似的商品，例如同样是面霜；也包含功能相似的商品，例如同样主打抗衰、修护或美白功效。这样召回不只依赖外观或标题相似，而是更贴近当前商品真正可以学习的广告表达。
  • 综合学习 Top-20，而不是复刻单条爆款。 只看少量视频容易让用户照搬脚本、动作或画面形式，却难以判断这些做法是否真正适合当前商品。Top-20 RAG 让系统从一组相似高表现案例中归纳可迁移的深层策略共性，帮助用户理解哪些表达可以迁移，哪些只是单条视频的偶然成功。
  • 给出不同策略组合，而不是只推荐一个方向。 系统将推荐组织成三种可选方向：一种重点参照与当前商品最相似的案例，一种重点参照高销量视频，一种重点参照高播放量视频。这样用户可以根据当前创作目标，在“商品适配”“销量表现”和“播放表现”之间选择更合适的策略组合。

RAG 召回策略

硬筛选：商品大类匹配
粗排：商品属性匹配
精排：需求价值匹配
精排：创意策略匹配
重排：效果表现重排
筛选字段 技术 例子（e.g. 抗老眼霜）
商品大类 规则硬筛 候选产品是面部护肤类。

03 分阶段生成：为什么不直接一键生成整片？

× 输入 Prompt 后直接生成完整视频

✓ 分阶段固定：分镜 → 故事脚本 → 视频片段 → 最终视频

  • 贴合真实创作流程： Amazon Ads 的 Video Production Guide 将视频广告流程拆为概念构思、脚本撰写、故事板生成、正式制作和后期制作等阶段，强调概念会指导脚本和视觉风格，脚本或故事板确认后再进入正式生产。这样的阶段划分能让创作者先确认整体方向，再逐步细化具体镜头和画面，减少后期大幅返工。
  • Ad Studio 支持分阶段反馈与固定： 分镜阶段可以修改场景、人物形象、产品展示方式和镜头距离，把关整体视觉方向；视频片段阶段主要调整旁白、动作和运镜，进一步细化具体画面表现。用户已经选定或满意的部分也能被固定下来，后续修改只围绕不满意的局部展开。

04 版本管理：为什么需要多版本比较？

× 只保留线性的生成记录

✓ 支持多版本保存、对比、回退和择优组合

  • 多版本比较是广告创作的常态： 同一个商品通常需要尝试不同钩子、展示方式和转化话术。上一版可能开头更抓人，这一版产品展示更清楚，另一版转化表达更适合投放。
  • Ad Studio 将版本迭代变成可管理流程： 系统保留不同阶段的候选版本，支持用户对比、回退和择优组合。这样多次生成不再只是堆积结果，而是可以围绕“哪一部分更好”持续收敛。

05 模型选型：为什么最终选择 Veo 3.1 Fast？

模型归属 Google / DeepMind
API 发布 2025 年 10 月
标准价格 $0.15 / 秒（约 ¥1.1 / 秒）
  • 参考图能力是硬性条件： Ad Studio 需要同时参考分镜图、产品图和人物 / 场景图，以保持人物、产品和画面设定一致；因此只有 Veo 3.1 / 3.1 Fast 符合要求。
  • 最终选择 Veo 3.1 Fast： 初测（20 条视频）中，Veo 3.1 与 3.1 Fast 的画面稳定性没有显著差别；因此我们选择成本更低、生成更快的 Veo 3.1 Fast。
