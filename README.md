# AIGC Video Ad Portfolio

Static portfolio page for an AIGC product manager case study.

## GitHub Pages setup

1. Create a new GitHub repository, for example `Ad_Studio-portfolio`.
2. Upload these files to the repository root:
   - `index.html`
   - `style.css`
   - `assets/`
3. In GitHub, open `Settings` -> `Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Select `main` branch and `/root`.
6. Save and wait for the generated Pages URL.

Resume link format:

```text
Portfolio: AIGC Video Ad Product Case Study
https://<your-github-username>.github.io/Ad_Studio-portfolio/
```
